# DILIVIRI - Documentación Oficial

## Aplicación Móvil de Comida a Domicilio

DILIVIRI es una aplicación móvil orientada a la gestión de pedidos de comida a domicilio.

El sistema permite a los clientes consultar restaurantes, seleccionar productos, realizar pedidos y consultar el estado de sus entregas.

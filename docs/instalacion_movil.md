# Guía de Instalación y Configuración del Entorno Móvil

## 1. Requisitos del Dispositivo / Emulador

### Sistema Operativo

- Android 8.0 (API Nivel 26) o superior.
- iOS 12.0 o superior, si la aplicación cuenta con versión para iOS.

### Almacenamiento

Se recomienda disponer de al menos 100 MB de almacenamiento libre.

### Conectividad

Es necesario contar con conexión a Internet o Wi-Fi para consumir los servicios de la API.

## 2. Requisitos para DILIVIRI

- Dispositivo móvil compatible.
- Conexión a Internet.
- Espacio suficiente para instalar la aplicación.
- Acceso a los servicios del servidor.

## 3. Procedimiento de Instalación

1. Descargar el archivo ejecutable de DILIVIRI.
2. En Android, habilitar la instalación desde fuentes desconocidas cuando sea necesario.
3. Ejecutar el archivo APK.
4. Conceder los permisos solicitados por la aplicación.
5. Esperar a que finalice la instalación.
6. Abrir DILIVIRI.
7. Verificar la conexión inicial con el servidor.
8. Registrarse o iniciar sesión.

## 4. Permisos

Los permisos solicitados dependerán de las funciones implementadas en la aplicación.

Por ejemplo:

- Ubicación, si se utiliza para la dirección de entrega.
- Notificaciones, para informar sobre el estado del pedido.
- Almacenamiento, únicamente si la aplicación realmente lo necesita.

## 5. Verificación

Después de instalar la aplicación, se debe comprobar que:

- La aplicación inicia correctamente.
- El usuario puede registrarse o iniciar sesión.
- Se pueden consultar restaurantes.
- Se pueden consultar productos.
- Se puede realizar un pedido.
- Se puede consultar el estado del pedido.

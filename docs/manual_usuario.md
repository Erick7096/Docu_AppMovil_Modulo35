# Manual de Usuario - DILIVIRI

## 1. Pantalla de Inicio y Registro

Al abrir DILIVIRI, el usuario visualizará la pantalla de bienvenida.

Si no posee una cuenta, debe seleccionar "Registrarse" e ingresar los datos solicitados.

Si ya posee una cuenta, debe seleccionar "Iniciar sesión".

## 2. Inicio

En la pantalla de Inicio el cliente puede consultar restaurantes y productos disponibles.

Desde esta sección puede seleccionar un restaurante para visualizar su menú.

## 3. Búsqueda

La sección de Búsqueda permite encontrar restaurantes o productos disponibles.

El usuario puede utilizar los filtros disponibles para encontrar opciones según las características ofrecidas por la aplicación.

## 4. Selección de productos

El cliente selecciona un restaurante y consulta los productos disponibles.

Para agregar un producto:

1. Seleccionar el producto.
2. Indicar la cantidad.
3. Presionar "Agregar al carrito".

## 5. Carrito

El carrito muestra los productos seleccionados por el cliente.

Desde esta pantalla puede:

- Aumentar cantidades.
- Disminuir cantidades.
- Eliminar productos.
- Consultar el total.
- Continuar al proceso de pedido.

## 6. Realizar pedido

Para realizar un pedido:

1. Revisar los productos del carrito.
2. Seleccionar la dirección de entrega.
3. Seleccionar el método de pago disponible.
4. Revisar el total.
5. Confirmar el pedido.

## 7. Estado del pedido

Después de confirmar el pedido, el cliente puede consultar su estado.

Los estados pueden representar diferentes etapas del proceso, por ejemplo:

- Pedido recibido.
- Pedido aceptado.
- En preparación.
- Listo para recoger.
- En camino.
- Entregado.

## 8. Notificaciones

La sección de Notificaciones permite consultar avisos relacionados con el pedido.

Por ejemplo:

- Confirmación del pedido.
- Cambio de estado.
- Pedido en camino.
- Pedido entregado.

## 9. Perfil

En Perfil el usuario puede consultar y administrar la información disponible de su cuenta.

## 10. Navegación Principal

DILIVIRI utiliza un menú de navegación inferior para facilitar el acceso a las secciones principales:

- Inicio.
- Búsqueda.
- Notificaciones.
- Perfil.

## 11. Actualización de información

Cuando la aplicación implemente actualización mediante gesto, el usuario puede deslizar la pantalla hacia abajo (Pull to Refresh) para actualizar la información mostrada.

## 12. Historial de Pedidos

El usuario puede consultar los pedidos realizados anteriormente y revisar la información disponible de cada pedido.

## 13. Calificación del Pedido

Después de recibir un pedido, el cliente puede calificar el servicio si esta función está disponible en la aplicación.
